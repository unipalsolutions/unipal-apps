# unipal-apps

UniPal internal app (Flutter): Android, iOS, Windows, macOS.

```sh
flutter pub get
cd apps/unipal
flutter run --dart-define=UNIPAL_API_URL=http://localhost:8000
```

Screens so far: sign-in, dashboard (pipeline totals and my tasks), task board, leads with lead details,
stage changes and activity logging. See `CLAUDE.md` for structure and rules.
